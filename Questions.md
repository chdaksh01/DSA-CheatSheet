Part 2: 10 Extra Must-Know Salesforce Questions (Not in the 191)
The Striver sheet is fantastic, but company-specific trends mean some classic problems are left out. Here are 10 highly frequent Salesforce AMTS questions you need to practice:

Print Matrix in Spiral Form: Very heavily asked in Salesforce online assessments and interviews to test basic matrix traversal implementation.

Group Anagrams: Uses Hash Maps with sorted strings or character counts as keys.

Meeting Rooms II: Finding the minimum number of conference rooms required. (The 191 list has Meeting Rooms I, but part II requires min-heaps or sweep-line algorithms).

Decode Ways (Possible Decodings): A classic DP problem where you find the total number of ways to decode a string of digits into letters.

Insert Delete GetRandom O(1): A system-design-adjacent coding problem where you must combine a Hash Map and an Array to achieve O(1) time complexity for all three operations.

Find All Anagrams in a String: A staple sliding window problem.

Word Ladder: The classic shortest-path problem on unweighted graphs using BFS to transform one word into another.

Top K Frequent Words: Similar to "K most frequent elements," but you must handle string sorting for ties. Often solved with a Trie + Min-Heap or Hash Map + Min-Heap.

Snake and Ladder Problem: A classic BFS traversal problem that tests your ability to model a game board as a graph.

Subdomain Visit Count: Tests string parsing and Hash Map manipulation.
